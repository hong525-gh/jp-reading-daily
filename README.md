# jp-reading-daily

每日 JLPT（N5～N1）日语阅读理解练习。

## 内容

- 每天按 JLPT 等级提供短篇阅读理解练习：一篇短文（通知、广告、邮件、日记、小故事等题材）配 3 道四选一理解题。
- 短文用词取自当天的复习与新学单词，帮助在阅读语境中掌握当天所学词汇的含义与用法。
- 答案与解析默认折叠，做完题目后自行展开核对。

## 目录与文件命名

按 JLPT 等级分目录，目录下按日期命名：

`等级/年-月-日-等级-序号.md`，例如 `N5/2026-08-10-N5-01.md` 表示 2026 年 8 月 10 日的 N5 第 1 篇。

在 GitHub 上直接点开任意 `.md` 文件即可阅读和做题，答案与解析默认折叠，做完后展开核对。
