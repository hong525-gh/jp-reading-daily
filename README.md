## 内容

- 每天按 JLPT 等级提供短篇阅读理解练习：一篇短文（通知、广告、邮件、日记、小故事等题材）配 3 道四选一理解题。
- 短文用词取自当天的复习与新学单词，帮助在阅读语境中掌握当天所学词汇的含义与用法。
- 答案与解析默认折叠，做完题目后自行展开核对。
- 正文后附有折叠的「📖 辅助阅读（分词・假名）」版块：点击展开可见全文的分词 + 振假名版本，读不懂句子时用来辅助断句与认读。

## 「辅助阅读」版块的分词原理

辅助阅读版由程序在文章发布时自动生成（不是手写）：

- **分词器**：[Sudachi](https://github.com/WorksApplications/Sudachi)（日本 Works Applications 开源的日语形态素分析器），Python 绑定 [SudachiPy](https://github.com/WorksApplications/sudachi.rs)，词典用 **SudachiDict-full**（信息量最大的官方词典）。
- **分割模式**：`SplitMode.C`——以最粗粒度切分（复合词尽量保持完整，例如「家族会議」作为一个词而不是切成「家族＋会議」），最接近阅读时的自然词感。
- **处理流程**：全文经 Sudachi 分词后，词与词之间插入空格显示断句边界；含汉字的词从词典读音（`reading_form`）取出读法、由片假名转为平假名，用 HTML `<ruby>` 标签标注振假名（例如 `<ruby>安心<rt>あんしん</rt></ruby>` 显示为「安心」上方小字 あんしん）；表记与读音一致的词（如纯假名词）不重复标注。
- 分词与读音全部来自词典离线数据，构建期一次性预计算，页面本身不含任何脚本。

## 目录与文件命名

按 JLPT 等级分目录，目录下按日期命名：

`等级/年-月-日-等级-序号.md`，例如 `N5/2026-08-10-N5-01.md` 表示 2026 年 8 月 10 日的 N5 第 1 篇。

在 GitHub 上直接点开任意 `.md` 文件即可阅读和做题，答案与解析默认折叠，做完后展开核对。
